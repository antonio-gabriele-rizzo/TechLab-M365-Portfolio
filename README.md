# TechLab Microsoft 365 Portfolio

## Overview

This repository documents my hands-on experience administering a Microsoft 365 tenant named **TechLab**.

The purpose of this lab is to develop practical IT support and Microsoft 365 administration skills aligned with entry-level IT roles such as:

* IT Support Technician
* Service Desk Analyst
* Junior Microsoft 365 Administrator

---

## Skills Being Developed

* Microsoft 365 Admin Center navigation
* User and license management
* Microsoft 365 Groups administration
* Exchange Online (mailboxes, shared mailboxes)
* Microsoft Teams administration
* SharePoint Online basics
* Security fundamentals (MFA, account protection)
* PowerShell for Microsoft 365

---

## Lab Environment

* Tenant: TechLab
* Platform: Microsoft 365 Business Basic
* Purpose: Self-learning IT administration environment
